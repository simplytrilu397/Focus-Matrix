# FocusMatrix 🎯

FocusMatrix is a modern, tab-based study planner designed to optimize your study schedule using the **Subject Priority Index (SPI)**, diagnostic practice quizzes, and an AI study assistant.

---

## ✨ Features

- **🏠 Daily Focus & Sprint:** Smart hero section highlighting your highest-priority topic with integrated Pomodoro timer.
- **⚡ SPI Calculator:** Calculate Subject Priority Index based on exam weight, difficulty gap, urgency, and confidence level.
- **📋 My Subjects & Topics:** Track subjects, syllabus coverage, exam deadlines, and difficulty ratings.
- **🧠 Diagnostic Practice:** Interactive practice questions with real-time scoring and diagnostic analysis.
- **💬 AI Study Assistant:** Built-in assistant to break down complex topics, explain concepts, and generate study strategies.
- **🌓 Dark & Light Modes:** Clean, accessible interface with toggleable themes.
- **🔐 Auth & Sign-in Flow:** Dedicated login and authentication interface.

---

## 🚀 Getting Started

Simply open [`index.html`](index.html) in your favorite web browser or serve with any static web server (like VS Code Live Server or `npx serve`).

```bash
# Optional: serve locally
npx serve .
```
